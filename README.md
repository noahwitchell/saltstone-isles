# Saltwhistle Skies

A cozy pixel-art flight game for phones: fly the mail around a small island, meet the locals, and learn to fly from Bea's logbook.

- Play: the GitHub Pages site serves `docs/` (add it to your home screen for full-screen play).
- Source: `src/head.html` (page + UI), `src/world.js` (island, rendering), `src/game.js` (flight model, mail, menus).
- Build: `python3 src/build.py` writes `game.html` (claude.ai artifact) and `docs/` (home-screen web app).
- `lookdev.html` is the original look-development page.
